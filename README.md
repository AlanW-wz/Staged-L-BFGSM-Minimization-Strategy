# Numerical experiments for staged L-BFGSM minimization

Code and archived numerical data associated with Section 3.1 of *Efficient Equilibration of Multicomponent PEDOT:PSS Systems Driven by a Staged L-BFGSM Minimization Strategy*.

**Scope:** the analytical-function benchmarks A, B and C. This package does not contain the GROMACS interface, molecular topologies, MD trajectories or SAXS data needed to reproduce Sections 3.2–3.3.

**Reproducibility status:** archived figure data can be regenerated numerically; the archived optimization implementations can be rerun. The final manuscript's five-step preliminary comparison differs from the method used by the archived benchmark curves. The two memory statistics in Table 3 do not have a complete recovered provenance chain. Read [the audit](AUDIT_zh.md) before claiming complete reproduction of the paper.

## Experiments

| ID | Paper location | Problems | Dimensions | Runs |
|---|---|---:|---|---:|
| A | §3.1.1; Fig. 1(a) | 9 | 10, 50, 100, 500 | 144 |
| B | §3.1.2; Table 3 | 7 | 10,000; 50,000; 100,000; 500,000 | 112 |
| C | §3.1.3; Fig. 1(b,c) | 11 | 10,000; 50,000; 100,000; 500,000 | 264 |

A uses 80 iterations, gradient tolerance 1e-6 and seeds `base_seed + dimension + 7`. B and C use iteration budgets 300, 150, 100 and 80, tolerance 1e-8, and seeds `base_seed + dimension`. Initial points are generated by `numpy.random.default_rng(seed).uniform(-3, 3, dimension)`. The problem sets and seeds are explicit in `src/suite.py`.

The archived A implementation uses L-BFGSM `(c0,c1,c2)=(0.9,1,1)`. The main C implementation uses `(0.25,1,1)`, memory 8, and `strategy5=False`. These choices preserve the source experiment rather than silently substituting the final manuscript's prose algorithm.

## Install

Use Python 3.12.7 to match the original numerical environment. From this folder:

```sh
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Verify and regenerate archived results

```sh
python verify.py
python replot.py
```

`verify.py` checks original-file SHA-256 hashes, all 17 analytical gradients, the complete 144/112/264 reference grids, original plotting-input hashes, Figure 1 aggregates, and Table 3's runtime/gradient/convergence columns. `replot.py` produces three PNGs, plot-data CSVs and a parameter-summary CSV under `results/reference_replot/`. The plotting layout is newly generated; the numeric curves match the archived plotting data. It does not generate MD or SAXS figures.

## Rerun optimization

First check that the environment works:

```sh
python reproduce.py --experiment all --smoke --out results/smoke
```

Smoke mode uses dimension 10 and a budget of 30 iterations. It is not a manuscript experiment. Full experiment commands:

```sh
python reproduce.py --experiment A --out results/run_A
python reproduce.py --experiment B --out results/run_B
python reproduce.py --experiment C --out results/run_C
# Or create a single complete output set for replotting:
python reproduce.py --experiment all --out results/full
python replot.py --data results/full --out results/full_plots
```

To check a single reported high dimension:

```sh
python reproduce.py --experiment C --dims 10000 --out results/C_10000
```

Use a new output directory for each command. Existing nonempty output directories are refused. Results are checkpointed after each run, but the new runner does not resume automatically. B and C at all dimensions can take substantial time. No independent time limit is imposed. The archived pure NCG implementation retains coordinate histories internally and can use substantial RAM at dimension 500,000.

The scripts use `time.perf_counter()`: the historical “CPU time” is elapsed wall-clock time. It depends on hardware, BLAS threads and system load. Do not expect timing values to match on another machine. SciPy line-search warnings can invoke the archived Armijo fallback. The solver implementations and their stopping semantics are preserved, including known numerical safeguards described in the audit.

Thread settings can also change floating-point optimization paths. During validation, 10 A cases differed when BLAS threads were forced to one; all 10 matched the historical gradient norms when rerun with this Python environment's default thread settings. B and C at dimension 10,000 matched their archived gradient norms, iteration counts and convergence flags in all 28 and 66 cases. See `validation/` for the comparisons and tolerances. Larger B/C dimensions were not fully rerun during packaging.

## Contents and provenance

- `legacy/`: byte-for-byte copies of 17 source scripts plus required archived data; preserved directory layout supports the historical plotting script.
- `src/`: three small modules extracted from original function bodies and an explicit experiment configuration/loader.
- `reference/`: selected A/B/C data and original plot-data CSVs. These are historical measurements, not newly measured results.
- `reproduce.py`, `replot.py`, `verify.py`: new portable entry points, aggregate processing and checks.
- `source_manifest.json`: relative original paths, copied paths, file sizes and SHA-256 hashes for every copied source file.
- `source_selection.csv`: inclusion/exclusion decisions for all discovered Python files in the experiment directory.
- `validation/`: checks and selected rerun evidence made while assembling this package.

`legacy/generate_afm_figures_1_3.py` can also regenerate the older individual Figure_1/2/3 exports; these correspond to final Figure 1(a/b/c), not three separate figures in the final paper. Legacy report scripts additionally require `requirements-legacy.txt`. Their old default problem sets and output paths are retained for provenance; use the new entry points for the final benchmark sets.

No Git history, manuscript PDFs, unrelated literature, credentials or environment directories are included. No public repository or license has been created by this packaging step. The project owner should supply the intended license and final citation before public distribution.
